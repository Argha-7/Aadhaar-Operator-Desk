# 🇮🇳 Aadhaar Operator Desk Assistant

A modern, high-speed operational assistant web application tailored for Aadhaar Enrolment & Update Centre operators.

---

## ⚡ Key Highlights
* **Biometric Animation Splash Screen:** Futuristic biometric laser scan & loading animation before launching the operator desk.
* **1-Tap Counter Tracking:** Quick token & service tallies across 3 UIDAI age groups (`Under 5`, `5 to 18`, `18 and Above`).
* **Official UIDAI Form Box Mapping:** Instant `(i)` guide showing exact mandatory form boxes for Form 1 (Adults), Form 3 (Minors), and Form 5 (Bal Aadhaar).
* **18 Movie-Style Counter Seats:** Real-time 4-per-row seating matrix (`01` to `18`), double-click toggle (Active/Closed), and hover tooltips.
* **WhatsApp Bulk Duty Roster:** 1-click paste for WhatsApp group seating lists with daily automatic refresh.
* **Operational Database & Audit Trail:** Automatic live timestamps, day breakdown, and Excel (CSV) master exports.
* **Silent Google Firebase Cloud Sync:** Pre-configured internal cloud synchronization with offline-first failover.
* **Vercel Cloud Deployment Ready:** Includes `index.html` and `vercel.json` for 1-click hosting.

---

## 🚀 Quick Start

### 1. Run Offline (PC or Mobile)
Simply double-click `index.html` or `Aadhaar_Kendra_Assistant.html` in any modern web browser (Google Chrome, Microsoft Edge, Safari). No internet connection is required.

### 2. Deploy to Vercel (Free 1-Click Cloud Hosting)
1. Fork or push this repository to GitHub.
2. Go to [Vercel](https://vercel.com) and click **"Add New Project"**.
3. Import this repository (`Aadhaar-Operator-Desk`) and click **"Deploy"**.
4. Your online Kendra URL will be live in 10 seconds!

## ⌨️ PC Keyboard Shortcuts
* **Keys `1` to `9` & `0`:** Instantly log count for Services 1 to 10.
* **Key `U`:** Instant Undo for accidental taps.
* **Key `Q`:** Switch to **Under 5 Years (Form 5)**.
* **Key `W`:** Switch to **5 to 18 Years (Form 3)**.
* **Key `E`:** Switch to **18 and Above (Form 1)**.
